# TVTC Dashboard

المؤسسة العامة للتدريب التقني والمهني — لوحة مؤشرات أداء البرامج التدريبية وأولويات البرامج الجديدة.

**Live:** https://malatshan.github.io/tvtc-dashboard/

## About

A single-page dashboard (Arabic, RTL) covering training-program performance
indicators and new-program priorities. The whole app is bundled into
`index.html`; there is no build step.

## Deployment

Pushing to `main` triggers `.github/workflows/static.yml`, which publishes the
repository root to GitHub Pages.
